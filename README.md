# Shopcart Core

Shopcart Core is a high-performance, modern e-commerce storefront prototype built with Next.js 15, React 19, and Tailwind CSS. It demonstrates a premium, app-like mobile experience and a multi-attribute digital catalog engine.

## Features

- **Premium UI/UX:** A sleek, aesthetic design featuring a dynamic homepage with hero sections, curated collections (New Arrivals, Trending), and immersive promotional banners.
- **Advanced Filtering Matrix:** An Amazon/Flipkart-style multi-faceted filtering system. Users can interactively filter products by Department (Men/Women/Unisex), Price Range (inputs & slider), Brands, Categories, Types, and Colors.
- **App-Like Mobile Experience:** Fully responsive design featuring a slide-over filter drawer, mobile-optimized 2-column product grids, and tight typography scaling for a native feel on smaller devices.
- **Reactive Product Cards:** Smart variant selection matrix that handles complex SKU availability (e.g., locking out sizes if a specific colorway is out of stock).
- **Client-Side Cart Context:** A global React Context managing the shopping bucket state.

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **UI/Styling:** Tailwind CSS (v4)
- **Language:** TypeScript
- **Icons:** Custom SVG Assets / React Icons

## Getting Started

First, install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
